Personal automation · Google Drive

Private, owner-operated file synchronization.

GDGS rclone is a private configuration of the open-source rclone tool, used by its owner to transfer project exchange packages between Google Drive and a local computer.

Purpose

Exchange project artifacts

The setup supports controlled transfers of GDGS engineering communication packages. It is not a consumer cloud-storage product or a service for other users.

Authorization

Owner-authorized OAuth

The owner authorizes rclone to access their Google Drive through Google's OAuth consent flow. Drive access is governed by the permissions granted to the OAuth client.

Synchronization directions

The transfer paths configured by the owner include:

Google Drive / AI_Communicator / todsh→Local computer / todsh

Local computer / togpt→Google Drive / AI_Communicator / togpt

Important: The OAuth client may request broader Google Drive permissions than these particular folders require. These paths describe the intended local synchronization workflow, not a technical restriction enforced by the Google OAuth scope.

How data is handled

File contents and metadata needed for synchronization are processed by the owner's local rclone installation and Google's Drive API. The website you are reading is informational: it has no sign-in form, file upload feature, or connection to your Google Drive.

The owner manages the local rclone configuration, credentials and transferred copies. The website does not request or store OAuth tokens.

For details about permitted uses, retention, security and contact information, read the privacy policy.

About this application

This project is a personal integration for GDGS (GPT–DSH–Gemini System). It uses rclone's Google Drive backend; it is not affiliated with Google or the rclone maintainers.

For general questions, see the developer's GitHub profile. For an account-specific OAuth support contact, use the support email shown on Google's consent screen. Do not publish OAuth tokens or personal file contents in a public GitHub issue.
