GDGS rclone · Data use disclosure

Privacy Policy

Effective date: October 22, 2026 · Applies to the personal GDGS rclone integration.

1. Operator and scope

GDGS rclone is a personal Google Drive integration operated by the owner of the sihaoyezhu GitHub account. It uses the open-source rclone client for automated file synchronization between a Google Drive account authorized by the owner and a local computer.

It is not a public application offered to other users. This policy describes the intended use of its Google OAuth client and the informational website hosted here.

2. Google data accessed

When authorized, rclone may access Google Drive file and folder names, identifiers, metadata and file content, as necessary to list, check, download or upload synchronization items. Depending on the selected OAuth scope, authorization may grant access to files beyond the specific folders currently used by the synchronization scripts.

OAuth tokens and client settings are maintained by the owner's local rclone configuration. This website does not ask visitors to connect a Google account or submit OAuth credentials.

3. How Google data is used

Google Drive data is used only for the owner-authorized synchronization workflow: retrieving GDGS exchange packages from a Drive folder to the owner's computer, uploading local exchange packages to a Drive folder, checking transfer integrity, and maintaining operational logs and status information.

The configured use does not involve selling Google user data, advertising, behavioral profiling, or training machine-learning models on Google Drive data. Any use beyond these purposes requires a separate decision by the owner and appropriate authorization.

4. Storage, disclosure and sharing

Transferred files can exist in both Google Drive and on the owner's local computer. Operational logs may record file paths, transfer results and error details. The local owner controls access to these copies and records.

This integration does not operate an independent public data-collection server or sell or share Google Drive content with advertisers or data brokers. Google processes Drive data as the Drive service provider. This informational website is hosted by GitHub Pages; website requests may be processed by GitHub under its own policies. The website itself includes no analytics script or advertising tracker.

5. Retention and deletion

Drive and local copies remain until the owner deletes or changes them using the relevant Google Drive or local file management tools. The synchronization arrangement is designed to copy files rather than automatically delete destination files. Logs and local credential configuration are retained according to the owner's local maintenance and backup practices.

The owner may revoke the application's access from Google Account connections. Revoking access prevents subsequent authorized API requests but does not automatically delete files already copied locally or stored in Drive.

6. Security

Google authorization takes place through OAuth. Credentials are handled by the local rclone installation, not by this static website. Protecting the local device, configuration file, backups and operating-system account is the responsibility of the operator. No claim of absolute security is made.

7. Google API data policy

The intended use of information obtained from Google APIs is limited to the functionality described above and is subject to the Google API Services User Data Policy, including applicable Limited Use requirements. No unrelated use of Google API user data is authorized by this website.

8. Questions and changes

For general questions, visit the developer's GitHub profile. For private OAuth support, use the user-support contact address displayed on the Google OAuth consent screen. Do not post private documents, credentials or access tokens in public issues.

This policy may be revised if the actual integration or data-handling practices change. Updates will be published at this URL with an updated effective date.
